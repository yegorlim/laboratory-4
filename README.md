## Висновок
Під час виконання лабораторної роботи №4 я набув практичних навичок складної обробки текстових даних засобами оболонки Unix-подібних ОС. Я навчився використовувати регулярні вирази для пошуку інформації в системних журналах git за допомогою утиліти grep. Також було успішно відпрацьовано автоматизовану модифікацію HTML-файлів за допомогою потокового редактора sed: виконано заміну тексту за шаблоном, додавання нових рядків та видалення порожніх рядків із збереженням команд у вигляді скрипту. Зміни успішно завантажені у нову гілку на GitHub.
